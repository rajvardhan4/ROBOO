WHAT IT DOES

TALK, IT ACTS

Press the mic or Ctrl+Space and speak in English, Hindi or Hinglish. ROBOO answers out loud.

ANY AI

Works with Gemini (free), Claude, OpenAI, Groq, OpenRouter, DeepSeek, Mistral, or local Ollama. Paste a key and it detects the provider.

CONTROLS YOUR PC

Opens apps and sites, incognito windows, volume, brightness, media, lock, files, typing and shortcuts.

WEB & INFO

Live web search, weather, YouTube, and it can look at your screen and explain what it sees.

INSTALL IN 1 MINUTE

Download ROBOO-Windows.zip with the button above.
Unzip it: right-click the zip, choose Extract All, and open the ROBOO folder.
Double-click ROBOO.exe. If Windows shows "Windows protected your PC", click More info and then Run anyway. The app is free and not code-signed.
Set it up: pick a nickname and paste an API key. A free Gemini key takes 30 seconds at aistudio.google.com/apikey.
Talk. Press the big mic or Ctrl+Space and say "Chrome kholo" or "aaj ka weather batao".

FAQ

Does it work on Android / iPhone?

Not yet. ROBOO controls a Windows PC, so it runs on Windows 10 and 11 only. You can still open this page on your phone and send the link to your computer.

Is it free?

Yes. The app is free. The AI is whichever key you bring, and Google's Gemini key has a free tier.

Where is my API key stored?

Only on your PC, in %APPDATA%\ROBOO\config\settings.json. It is sent only to the AI provider you chose.

Windows says the app is unrecognised

That is SmartScreen warning about any new, unsigned app. Click More info, then Run anyway. The full source code is on GitHub if you want to check it.
